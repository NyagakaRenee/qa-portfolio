## Background

**QA attachment, Kiwami Tech (June to September 2025).** I worked in a four-person team testing a mobile Service Management App (Guard and Resident apps) for gated communities. My work included:

- Writing and executing manual test cases, and documenting results
- Building and maintaining a Requirements Traceability Matrix (RTM)
- Logging defects with reproduction steps, severity and priority
- Contributing to the test plan and the QA report
- Working in an Agile setup with daily stand-ups, sprint planning, reviews, retrospectives and a bug bash

Team results: 110 test cases (100 passed, 10 failed) and 10 defects logged.
